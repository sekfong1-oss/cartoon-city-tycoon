# Cartoon City Tycoon Online V5.1 — Contrast Fix

This release improves text visibility and readability across all visual themes.

## What was fixed
- Title and subtitle contrast in the top hero card
- Form labels and select/input readability
- Room/lobby information visibility
- Main panel/card text contrast
- Board tile label readability
- Center board information visibility
- Theme-safe text colors for Fusion, Realistic, Cyber and Luxury themes

## Existing features retained
- 2–12 online players
- auto reconnect
- text chat
- WebRTC voice
- live auctions
- mini-games
- multiple visual themes
- low exciting background music
