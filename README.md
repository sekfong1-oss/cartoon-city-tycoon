# Cartoon City Tycoon Online V6.3 — FX Celebration Edition

This version adds the three requested presentation upgrades.

## 1) Dice jump / landing sound effects
- dice jump now has a rising arcade-style sound
- final dice landing has a stronger impact / thump sound
- landing also shakes/bounces the dice area

## 2) Animated property purchase effect
When a player successfully buys a property:
- the tile pops forward in 3D
- SOLD badge appears
- coins burst from the tile
- house / sparkle effects appear
- purchase sound plays

## 3) Winner celebration screen
When the game ends:
- winner portrait appears
- victory fanfare plays
- confetti falls
- fireworks explode
- winner panel zooms in
- restart/rematch buttons remain available

## Existing V6.2 features retained
- 2–12 online players
- custom uploaded avatars
- rarity avatar frames
- character skin styles
- token name tags
- jump/roll 3D dice with large pips
- stronger 3D board camera movement
- rematch/restart
- jackpot
- doubles
- street duels
- chaos events
- mini-games
- chat / voice / reconnect
